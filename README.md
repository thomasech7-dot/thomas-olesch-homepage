# Thomas Olesch Homepage

One-page homepage for Thomas Olesch Copywriting.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The Website-Röntgen stays in the separate `webseite-roentgen` project.
- This homepage links to the Website-Röntgen as a separate offer.
- Current image assets are loaded from the existing Website-Röntgen deployment until final domain and asset handling are decided.
